# GitHub V6 多并发注册

本项目使用 GitHub Actions 原生矩阵和 RuyiPage Firefox 执行 GitHub 注册流程。每个矩阵任务只领取一个邮箱，使用 GitHub 托管 runner 的直连网络，完成注册表单、Microsoft Graph 邮件取码、成功页面确认和首次登录后才写入成功结果。

## 能力边界

- 单次最多 256 个任务。
- 最大并发 20，实际并发不会超过任务数量。
- 每个邮箱只提交 1 次注册；验证码读取和重发始终留在同一浏览器会话。
- 不读取代理文件，不启动代理程序，也不向浏览器传入代理设置。
- 单个任务失败不会取消其他矩阵任务。
- 只有验证码已提交、页面出现精确成功提示且同一浏览器首次登录成功的账号才算成功。
- 失败、未知、损坏、缺失或邮箱不一致的结果不会删除邮箱。

## 邮箱文件

在项目根目录的 `email.txt` 中每行放一个邮箱凭证：

```text
邮箱----邮箱密码----client_id----refresh_token
```

四个字段都不能为空。邮箱比较、重复检查和成功删除不区分大小写，密码和令牌不会写入普通日志。矩阵索引从 1 开始，第一个任务固定领取第一条邮箱，第二个任务领取第二条邮箱。

## 启用工作流

1. 将本目录作为独立仓库推送到 GitHub。
2. 在仓库 `Settings > Actions > General > Workflow permissions` 中选择允许读写仓库内容。
3. 打开 `Actions`，选择 `GitHub V6 多并发注册`。
4. 点击运行工作流并填写任务数量、最大并发和三个超时值。

`任务数量` 留空时自动使用邮箱池容量与 256 的较小值。填写时必须是 `1-256`，并且不能超过当前邮箱数。`最大并发` 必须是 `1-20`。

## 执行流程

### 准备任务矩阵

准备任务校验 `email.txt`、任务数量、并发和超时范围，输出从 1 开始的唯一矩阵索引。工作流按仓库和分支设置并发组，同一分支的两个批次会排队，不会同时领取同一批邮箱。

### 注册账号

每个 GitHub 托管 runner：

1. 安装 Python 3.12、RuyiPage Firefox 和 Xvfb。
2. 按矩阵索引领取唯一邮箱。
3. 使用邮箱密码作为 GitHub 密码。
4. 使用邮箱本地部分前 5 位、3 位随机数字和第 6 至 9 位生成用户名。
5. 填写表单、勾选邮件偏好和 GitHub Copilot，等待 5 秒后点击创建账号。
6. 进入验证码页后，通过当前浏览器会话的同源请求额外重发一次验证码。
7. 等待 5 秒后通过 Microsoft Graph 读取邮件，每组三次；三次均未读到则在当前页面再次重发，直到成功或邮件超时。
8. 输入 8 位验证码，并等待精确成功提示。
9. 在同一浏览器打开登录页，输入刚注册的邮箱和密码。
10. 无设备验证时等待 Dashboard；出现 `#otp` 时读取 GitHub 6 位设备验证码，输入后再次等待 Dashboard。
11. 只有 Dashboard 或已认证用户元数据得到确认才写入成功结果，并始终上传中文日志、结构化结果和失败截图。

### 汇总并自动提交

汇总任务始终运行，只接受完整且可重新校验的成功结果。它会基于远端最新分支幂等更新 `注册成功账号.txt`，从 `email.txt` 原子删除已确认成功的邮箱，然后自动提交并推送。发生推送冲突时最多重新拉取、重新计算和推送 3 次，不会用旧邮箱池覆盖远端新增记录。

成功账号使用固定格式：

```text
账号：邮箱
密码：密码
用户名：用户名
API：
邮箱----密码----client_id----refresh_token
```

## 结果和隐私

- `注册成功账号.txt` 是仓库内的预期成功输出，会包含账号凭证。
- 成功任务 Artifact 也会包含完整成功账号，默认保留 7 天。
- 汇总任务会上传名为 `ALL-全部账号-v6` 的完整账号附件，默认保留 7 天。
- 失败结果只包含脱敏错误摘要，不包含密码、client_id、refresh_token 或完整 API 行。
- 不要公开包含真实 `email.txt`、`注册成功账号.txt` 或成功 Artifact 的仓库。

## 本地离线验证

安装测试依赖并运行：

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
```

离线测试使用临时邮箱、伪页面和伪 Graph 响应，不启动真实浏览器，不访问 GitHub 或 Microsoft Graph，也不会读取项目根目录的真实邮箱文件。
